# Controls

These are the default controls for the current Godot alpha. Some keys change behavior when a menu or station window is open.

## Movement and world actions

| Input | Action |
| --- | --- |
| A / D or Left / Right | Walk |
| Space / W / Up | Jump or rise through water |
| W / S or Up / Down | Climb a ladder |
| Space while climbing | Jump off the ladder |
| Mouse movement | Aim your held tool or weapon |
| Left mouse button | Mine, attack, or use the selected tool/spell |
| Hold left mouse button | Repeat supported mining/tool actions; draw a bow |
| Release left mouse button | Release a drawn bow shot |
| Right mouse button | Place or use the selected item; ranged weapons can select ammunition |
| F | Interact with the aimed station, chest, furnishing, power device, or nearby expedition object |
| E | Talk to R0-VR when nearby |
| G | Return to orbit when expedition progression permits |

## Inventory and equipment

| Input | Action |
| --- | --- |
| I | Open or close the backpack |
| C | Open basic crafting |
| M | Open the build/crafting menu |
| 1–9 | Select a slot on the current hotbar page |
| Mouse wheel / Tab | Cycle slots on the current page |
| Alt + mouse wheel | Switch hotbar pages |
| B | Cycle hotbar pages |
| Ctrl + left-click a backpack item | Add it to a free hotbar slot |
| Ctrl + click a hotbar slot | Remove that shortcut |
| Drag an item | Move/assign it to a supported inventory or hotbar destination |
| Q | Toggle an owned pickaxe / empty hand |
| H | Toggle an owned hoe / empty hand |
| T | Cycle owned tools |
| V | Equip an owned watering can and water the aimed soil |
| R | Quick-eat available food |
| K | Open the magic skill and spell guide |

## Menus and saves

| Input | Action |
| --- | --- |
| Esc | Close the current window or open the pause/session menu |
| Enter at an open workbench | Craft the selected recipe |
| Up / Down in basic crafting | Change the selected recipe |
| J | Expand or collapse expedition objectives |
| F5 | Save; multiplayer saving is host-managed |
| F9 | Load in single-player; disabled during an active multiplayer session |
| F3 | Open developer controls on the planet, galaxy, or system view; host-only in co-op |

Windows can be dragged by their title bars and closed with their close buttons. The host's session menu does not pause a multiplayer world.
