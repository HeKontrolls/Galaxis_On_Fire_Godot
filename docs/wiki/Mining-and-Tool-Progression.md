# Mining and Tool Progression

Mining combines reach, material hardness, tool suitability, and harvest level. Hold the left mouse button to continue working on a reachable block. Mining reach is limited to **four blocks from the player**.

## Choose the right tool

| Tool | Main use |
| --- | --- |
| Pickaxe | Stone, ores, and other tier-gated materials |
| Shovel | Dirt, sand, snow, and other soil materials |
| Axe | Trees and wooden materials |
| Hoe | Tilling soil and managing crops |
| Watering Can | Watering tilled soil |
| Hammer / Mattock | Background deposits and supported background/decorative work |
| Sword | Combat; cannot mine blocks |

Pickaxes work poorly on trees and soil compared with the appropriate tool. Axes also take time to dig soil. Tree chopping requires multiple hits, with stronger axes making more progress per hit.

## Pickaxe tiers

| Material | Mining level | Maximum pickaxe durability |
| --- | --- | --- |
| Wood | 0 | 59 |
| Gold | 0 | 32 |
| Stone | 1 | 131 |
| Copper | 1 | 191 |
| Iron | 2 | 250 |
| Diamond | 3 | 1,561 |
| Netherite | 4 | 2,031 |

Gold has high mining power but a low harvest level and short durability. It does not replace an iron or diamond pickaxe for higher-tier materials. Pickaxes and shovels support all seven materials; other tool families have their own available upgrades.

## Harvest requirements

| Material | Minimum pickaxe level |
| --- | --- |
| Stone, cobblestone, coal, glacial ice | 0 |
| Copper ore, iron ore | 1 |
| Gold ore, alien crystal, diamond ore | 2 |
| Obsidian, ancient debris | 3 |

The starter wooden pickaxe can mine stone and coal, but cannot skip directly to copper or iron ore.

## Power and swing speed

Mining swings use a consistent cadence. Better tools increase work done per hit; they do not simply make the visible mining animation spin faster. Check the tool information and remaining durability in the HUD.

Dropped materials are attracted toward nearby players. Natural ore deposits use terrain artwork, while some inventory icons use element symbols and atomic numbers. Alien crystal remains an unknown element, marked with question marks.
