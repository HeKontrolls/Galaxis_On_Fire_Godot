# Ground flora and fauna

`ground_cover.aseprite` adds the fuller reference-inspired bushes and natural ground rocks. Its transparent canvas is 48 x 40 with pivot (24,40), four named layers, ten tags and 28 frames: leafy bush, forest thicket, flowering bush, frost bush, pebble cluster, granite boulder, mossy boulder, sandstone rock, basalt rock and woodland mushrooms. Bushes, mushrooms and the moss overlay have four poses; the other rocks have one rigid pose. This brings the ecology set to 32 types and 116 frames across two native Aseprite documents.

`tools/design_ground_cover_aseprite.lua` constructs that document using Aseprite's native drawing API, and revises only the berry-shrub tag in the original document into a continuous leafy dome. All other original species remain intact. Use `tools/export_aseprite_art.ps1` after normal edits; it exports both documents. `tools/verify_ground_cover_aseprite.lua` compares the new exports against all native visible pixels. The main verifier also invokes it.

The subsequent detail revision lives in `tools/redesign_ground_cover_detail_aseprite.lua`; the construction helper now runs it automatically. It redraws the existing cover frames in Aseprite while retaining their canvas, pivots, tags, durations and layer count. Leaf sprays, branch forks and overhanging fronds give the bushes distinct silhouettes. The flowering shrub has layered pink blossoms and buds; the frost shrub has silver twig tips and berries. Granite is low and weathered, the mossy stone has a split upright face and fern growth, sandstone has eroded horizontal beds, basalt forms broken columns, and the mushrooms have curved stalks, cap markings and gills. The compact berry shrub receives the same foliage treatment. Runtime selection heights follow the revised taller flowers, stone sprouts and mushroom caps.

The latest rock direction follows John's closer surface-rock references. `tools/redesign_ground_rocks_reference_aseprite.lua` and then `tools/refine_ground_rocks_closeup_aseprite.lua` run after the detail pass. Only the five rock tags are redrawn. Small stones form low ground clusters; the mossy variant is an interlocking pile with deep seams and vivid emerald moss and grass around individual chunks. Large polished facets, tall sprouts and basalt columns are replaced by the new surface-rock shapes. Existing rock names, pivots, canvas, tag ranges and saved object identities are retained. `tests/ground_rocks_reference_review.png` shows enlarged details and actual size beside the player. The preceding document is archived as `archive/ground_cover_before_reference_rocks.aseprite`.

The earlier source documents are retained under `archive/ground_cover_before_detail.aseprite` and `archive/ground_life_before_detail.aseprite`. `tests/ground_cover_before_detail.png` retains the previous review board. These are backups; normal exports read the current documents above.

`ground_life.aseprite` is the editable source for all 22 new surface species. It has a transparent 24 x 32 canvas, three named layers, and 22 animation tags containing four frames each (88 frames total). All pixels and animation poses were created through Aseprite's native Lua API. The common ground pivot is (12,32).

The plants are meadow grass, wildflowers, ferns, berry shrubs, reeds, broadleaf plants, dry grass, cacti, frost grass, moss, lichen, crystal blooms, ice coral and ember fronds. The fauna are beetles, butterflies, snails, sand hoppers, snow moths, ember mites, burrow hares and ground birds.

Open the document in `C:\Program Files\Aseprite\Aseprite.exe`, edit the layers and tag frames, then save. Keep the established tag names and ground pivot. Export the saved art with the project's `tools/export_aseprite_art.ps1`, which also invokes `tools/export_ground_life_aseprite.lua`. Runtime PNGs and metadata go to `assets/sprites/ground_life/`. The export helper never repaints the saved artwork.

The initial construction script is `tools/design_ground_life_aseprite.lua`. Running it rebuilds this document, so use the ordinary export helper after hand edits. If reconstructing from the initial scripts, run `tools/design_ground_cover_aseprite.lua` afterward to retain the fuller berry shrub. `tools/verify_ground_life_aseprite.lua` compares every exported visible RGBA pixel with the native document and checks the canvas, layer, tag and frame counts.

Godot reads both sets of Aseprite frames in `scripts/ground_life.gd`. Runtime mesh bending uses each texture's actual size and keeps the ground pivot fixed while wind and player contact displace vegetation. Rocks remain rigid and outside the solid tile grid, so the player can pass through them. Pickaxes take multiple hits to collect larger rocks. All cover uses its own saved population version, permitting one safe addition to older ecology saves without replacing existing objects or harvested patches. Species, positions and harvested state persist in world saves. Collectibles use the same native artwork for dropped items, backpack icons and replanting/releasing, with their original proportions preserved.
